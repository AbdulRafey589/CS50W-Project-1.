# C Programming Language

**C** is a general-purpose, procedural programming language developed by **Dennis Ritchie** at Bell Labs in the early 1970s. It is widely used for system programming, operating systems, embedded devices, compilers, and performance-critical applications.

## Definition

C is a **compiled, low-level but portable** language that gives programmers direct control over memory through pointers. It provides a small set of core features and relies on standard libraries for input/output, string handling, and mathematical operations.

## Key Features

- **Compiled language:** Source code is converted into machine code before execution.
- **Fast and efficient:** Suitable for performance-sensitive programs.
- **Portable:** C programs can often run on different operating systems with little or no modification.
- **Low-level access:** Supports pointers and manual memory management.
- **Structured programming:** Uses functions, loops, conditionals, and blocks.
- **Standard library:** Provides functions such as `printf()`, `scanf()`, `malloc()`, and `strcpy()`.
- **Foundation for other languages:** Languages such as C++, Java, Python, and JavaScript have been influenced by C.

## Basic Syntax

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

## Common Data Types

| Data Type | Purpose | Example |
|---|---|---|
| `int` | Whole numbers | `int age = 16;` |
| `float` | Decimal numbers | `float price = 9.99;` |
| `double` | Larger decimal numbers | `double pi = 3.14159;` |
| `char` | Single character | `char grade = 'A';` |
| `char[]` | String of characters | `char name[] = "Rafey";` |
